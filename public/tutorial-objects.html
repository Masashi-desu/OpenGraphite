NO ANNOTATION · SESSION REF

標準 HTML のまま

既存の標準 id と安全な selector を優先して inspection します。ページを開く、または無編集で保存しても optional annotation は増えず、source は書き換わりません。

PARTIAL ANNOTATION · SESSION REF

必要な情報だけ存在

data-og-id だけがある状態も有効です。不足している annotation は validation error ではなく、参照の安定性として区別されます。

COMPLETE ANNOTATION · STABLE REF

明示 Adopt 済み

安定した AI mutation が必要な node だけに optional ID を付与します。Adopt は dry-run、source diff、apply 後の stable reference を返します。
