Typography

文字の階層、行間、label表現をlocaleを含めて定義します。

Font 書体と文字サイズの階層。 DisplayBody and label scale Displayと本文を同じtype scaleから選択します。
Role
display、heading、body、label、monoの階層。
Tokens
--font-family-* / --font-size-*
States
強調はweightとhierarchyで示す。
Layout
自然改行と読みやすい行長を優先。
Accessibility
200% zoomでも情報を維持。
Usage
:lang()でlocale typographyを選択。
 Line 行間と可読性の基準。 Tight
lineReadable
body copy 見出しにはtight、本文にはreadableな行間を使います。
Role
文字ブロックの読み進めるrhythm。
Tokens
--line-height-*
States
状態差ではなくcontent階層を表す。
Layout
見出しはtight、本文はbodyを使用。
Accessibility
行間を変えても文字をclipしない。
Usage
文字サイズと用途を組にして選択。
 Text ラベルと本文の文字表現。 uppercase labelnormal reading text ラベルと通常本文のhierarchyを比較します。
Role
labelと本文の視覚的な役割分担。
Tokens
--font-weight-* / --text-transform-label
States
weightだけに状態の意味を依存しない。
Layout
本文は自然改行、labelは短く保つ。
Accessibility
大文字表記だけで意味を区別しない。
Usage
metadataはlabel、説明は通常本文。
