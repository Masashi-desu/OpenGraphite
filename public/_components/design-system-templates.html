RULES

Template composition rules

Atomic Designの階層を守りながら、実装とデザインの責務を混ぜないための規則です。

01 / Structure

DOM order first

視覚配置より先に、読む順序とkeyboard順序が自然なDOMを決めます。

02 / Layout

Standard CSS

Flex/Grid、gap、padding、breakpointをcompanion CSSの標準propertyで表します。

03 / Difference

Explicit source

共有はmaster、差分はslot/page CSS、previewだけの値は.ogpに保持します。
