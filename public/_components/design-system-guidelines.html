INTERACTION

Interaction & state

操作可能性、状態、feedbackを同じ語彙とsource境界で表現します。

State vocabulary

  • rest / hover / focus / active / disabled
  • loading / empty / error / success
  • expanded / collapsed / selected

Standard source

  • ARIAは標準attribute
  • component stateはhost variant
  • preview-only stateは.ogp mock
  • --color-focusはfocus indicatorだけに使用
  • elevationは共有--shadow-*を加工せず使用

Feedback

  • 100ms以内に操作受付を示す
  • 色だけに依存しない
  • 失敗時は回復方法を添える
Do

aria-expanded と表示状態を同期し、keyboardとpointerに同じ結果を提供します。

Don’t

editor previewのための一時状態をsource HTMLへ固定しません。

CONTENT

Content & localization

短く正確なcopyと、locale resource / fallbackの責務を明確にします。

Voice

直接的、具体的、source-first。抽象的なmarketing語より、何ができてどこへ保存されるかを書く。

Action labels

「Click here」ではなく「Read Docs」「Download OpenGraphite」のように結果を明示。

i18n

翻訳文はlocale resource。HTML fallback、data-i18n-key、root :lang() typographyを分離。

Terminology
Page、Component、Canvas、source、master、slotを一貫して使用。
Numbers
単位、範囲、version、commandを省略せず記述。
Error copy
起きたこと、影響、次の行動を順に説明。
ACCESSIBILITY

Accessibility

component、template、pageのすべてで満たす最低条件です。

Semantics

Native first

button、link、nav、header、main、headingを目的どおりに使い、roleで不要に再実装しません。

Keyboard

Full path

すべてのactionへ到達でき、focus順がDOM orderと一致し、trapから抜けられること。

Perception

More than color

text、icon、shape、ARIAを組み合わせ、contrastと200% zoomでも情報を維持。

  • icon-only controlは識別可能なaria-labelを持つ。
  • focus indicatorを削除せず、背景とのcontrastを維持する。
  • heading levelを見た目の大きさではなく文書階層で選ぶ。
  • 画像は目的に合うalt、装飾画像は空altまたはpresentationとして扱う。
MOTION

Motion

移動を装飾ではなく、関係と状態変化の理解に限定します。

Duration
micro feedback 120–180ms、panel transition 180–260msを基準。
Easing
enterは減速、exitは短く、連続操作を待たせない。
Property
opacity / translateを優先し、layout thrashを避ける。
Reduced motion
prefers-reduced-motionで移動を抑え、情報は即時表示。
Persistence
drag/reorder previewはsession-onlyで、authored transformを上書きしない。
Feedback
完了、失敗、選択の意味が静止状態でも理解できる。
RESPONSIVE

Responsive behavior

device名ではなく、contentが破綻する点でlayoutを切り替えます。

Priority

title、primary action、本文、補助visualの順で重要情報を維持。

Reflow

3-column → 2-column → 1-column。横scrollで本文を隠さない。

Targets

狭幅でも操作target、focus ring、code wrapping、navigation labelを保持。

Do

実際の@media条件とviewportのcomputed resultを同じ条件で検証します。

Don’t

desktop DOMとmobile DOMを重複させ、contentやARIAの別正本を作りません。

GOVERNANCE

Governance & contribution

変更理由、source、利用例、検証を同じ変更単位に保ちます。

  1. 01 / Propose問題、利用者、Atomic level、再利用範囲を記述。
  2. 02 / AuthorHTML master、companion CSS、token、page usageを更新。
  3. 03 / Verify構造、state、keyboard、responsive、locale、buildを確認。
  4. 04 / Releasebreaking change、migration、version、documentationを同期。
Source

One truth

masterはCollection内HTML、design valueは標準CSS、project-wide共有値はCSS Custom Properties。

Change

Keep the unit whole

component、利用ページ、documentation、test/validationを理由なく別変更へ分断しない。

Gate

Definition of done

ogkiln validate、screenshot、build、Scripts/quality_gate.shを完走。
