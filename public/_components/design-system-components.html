MOLECULES

Molecules

単一の短い目的を果たす、小さな部品の組み合わせです。

Molecule

Section heading

<section-heading>

章のeyebrowとtitleを一貫した階層で提示します。

Anatomy
eyebrow + title
API
slot="eyebrow"、slot="title"
Variants / states
Variantなし。文言差分はslotで渡す。
Layout
縦stack。親幅に追従し、見出しは自然改行。
Accessibility
利用側で文書階層に合う見出しsemanticを保持する。
Usage
大きなcontent sectionの入口。短いeyebrowを推奨。
Molecule

Feature card

<feature-card>

機能やavailabilityをeyebrow、title、bodyで要約します。

Anatomy
eyebrow + title + supporting body
API
eyebrow、title、body slots
Variants / states
variant="availability" をhostで表現。
Layout
縦stack、token化されたgapとcard padding。
Accessibility
色だけで状態を伝えず、title/bodyにも状態を書く。
Usage
機能紹介、release availability、短い要約。
Molecule

Principle item

<principle-item>

番号付きの原則を、titleと本文で説明します。

Anatomy
number + title + explanatory body
API
number、title、body slots
Variants / states
状態なし。順序は親listの情報設計に従う。
Layout
番号railと本文。狭い幅では縦方向へreflow。
Accessibility
順序に意味がある場合は利用側でolを使う。
Usage
原則、手順、優先順位、decision heuristic。
Molecule

Doc row

<doc-row>

index、title、説明、metaを横断的に揃える文書行です。

Anatomy
index + title + body + meta
API
index、title、body、meta
Variants / states
単一variant。metaは省略可能。
Layout
3-column document row。mobileでは縦stack。
Accessibility
indexだけに意味を依存せずtitleで内容を識別する。
Usage
機能一覧、API一覧、仕様の章立て。
Molecule

Doc code row

<doc-code-row>

doc rowに実行可能なcode例を加えた派生部品です。

Anatomy
index + title + body + code block
API
index、title、body、code
Variants / states
単一variant。codeは改行を保持する。
Layout
doc rowと同じgrid。codeは横overflowを避ける。
Accessibility
code前後に目的と結果を自然文で説明する。
Usage
CLI、MCP、設定、短いHTML/CSS例。
ORGANISMS

Organisms

ページ内で独立した責務を持つ機能ブロックです。構造とinteractionの境界を明示します。

Organism

Site header

<site-header>

ブランドと主要navigationを束ねるglobal headerです。

OpenGraphite DS Overview Atoms Components Templates Pages Guidelines Web Pages
Anatomy
app mark + brand link + menu toggle + primary navigation
API
slot="brand"、繰り返し可能なslot="nav"
Variants / states
現在位置はaria-current="page"、領域間の切替はsite-header-switcherで示す。
Layout
brandを左、navigationを右へ配置。収まらない場合は高さを変えずmenuへ切り替える。
Behavior
実際のcontent幅を測定し、menuの開閉とaria-expandedを同期する。
Accessibility
navigation landmark、識別可能なlink text、native button、Escapeで閉じる操作を提供する。
Usage
Web pagesとDesign Systemで共通利用し、文言と遷移先はslotで渡す。
Organism

Content section

<content-section>

主説明と補助actionを2-columnで配置します。

Anatomy
content copy + optional aside action
API
title、body、aside slots
Variants / states
asideの有無で情報密度を調整。
Layout
content + aside。mobileでは本文を先に縦stack。
Accessibility
action labelは遷移先や結果を具体的に記述。
Usage
リポジトリ、download補足、関連documentation。
Organism

Docs navigation

<docs-navigation>

長い文書を移動するcollapsible navigationです。

Anatomy
section links + collapse / open control
API
host variant と固定navigation structure
Variants / states
collapsible、collapsed。preview stateは.ogp。
Behavior
controlがhost variantとaria-expandedを同期。
Accessibility
button label、keyboard操作、現在位置を色以外でも表現。
Usage
Docs templateの左rail。短いページでは使用しない。
Organism

Code viewer

<code-viewer>

code、optional preview、copy actionを一つの学習面にまとめます。

Interactive
Code only
Anatomy
language + actions + code panel + optional preview panel
API
language、code、preview slots
Variants / states
preview、切り替えを省くcode-only、tabのaria-pressed。
Behavior
通常版はcopy feedbackとcode / preview切替。code-onlyはcopyのみを提供する。
Accessibility
icon buttonにlabel、選択状態をARIAで公開、focusとreduced motionを保持。
Usage
実表示との比較には通常版、HTML/CSS/CLI例だけを示す場合はcode-only。
